# Главная страница

Реализация начата 29 сентября 2026 года по прямому поручению владельца на основе `projects/tasks/001--redesign/homepage-concept-v2.png`.

## Структура

- `Hero/`: заголовок, поиск и декоративная иллюстрация.
- `BeerSelection/`: три настоящих материала о пиве с исходными изображениями.
- `Places/`: переход к заведениям с декоративной иллюстрацией кафе.

У каждого блока собственный `styles.ts`; изображения находятся в его `assets/`. Шапка и подвал входят в общий `app/components/Layout/`. Используются системные шрифты Georgia и Arial без внешней загрузки.

## Контент и переходы

Иллюстрации первого экрана и кафе созданы ImageGen; они не изображают конкретное пиво или реальное заведение. На первом экране есть подпись «Иллюстрация». Фотографии карточек ранее перенесены из старого каталога и хранятся локально в `BeerSelection/assets/`. Во время работы сайта изображения не загружаются со старого сайта.

Все внутренние ссылки относительные и обслуживаются новым приложением. Каталог заведений открывается на `/companies`, карточки — на `/place/<place_id>/<url_name>/`. Пиво (`/beer/showlist/`, `/beer/<id>/<slug>`), публикации (`/blog/showlist/`), города (`/city/`), контакты (`/contacts.html`) и владельческие сценарии (`/places/create/`) сохраняют локальные ссылки и пока возвращают 404. Это показывает запланированную структуру, не выдавая страницы за реализованные.

Форма поиска выполняет локальный GET-переход в `/beer/showlist/?name=...` через React Router. Пока каталог пива не реализован, результат — локальная 404. Подборка статическая, без заявлений о рейтинге или наличии.

SEO использует `VITE_SITE_ORIGIN` (по умолчанию `http://localhost:3000`); при запуске на другом адресе следует задать адрес этого окружения и пересобрать сайт. `robots.txt` и `sitemap.xml` формируются маршрутами из адреса входящего запроса. Sitemap содержит только реализованные статические страницы: главную и каталог заведений.

## Проверки

### Оптимизация изображений

29 сентября 2026 года четыре изображения переведены в WebP через установленный Sharp 0.35.5 (`effort: 6`). Оригиналы сохранены рядом для повторной обработки, но компоненты импортируют только оптимизированные файлы; оригиналы не попадают в сборку.

| Изображение  | Размер WebP | Качество Sharp | Было → стало  |
| ------------ | ----------- | -------------- | ------------- |
| Первый экран | 1536×1024   | 84             | 1960 → 103 КБ |
| Кафе         | 600×400     | 82             | 1674 → 17 КБ  |
| Cernovar     | 250×250     | 85             | 163 → 15 КБ   |
| Kult         | 250×250     | 85             | 95 → 9 КБ     |

Кафе выводится максимум в 260×170 CSS-пикселях; уменьшенная версия сохраняет запас для экрана с двойной плотностью. Разрешение крупной иллюстрации сохранено для широких экранов. Прозрачность фотографий Cernovar и Kult сохранена. «Бархатное» (9 КБ, 150×160) оставлено без повторного сжатия и увеличения.

Для повторной обработки из корня проекта (пример кафе):

```sh
node --input-type=module -e "import sharp from 'sharp'; await sharp('app/pages/MainPage/Places/assets/cafe.png').resize({width:600,withoutEnlargement:true}).webp({quality:82,effort:6}).toFile('app/pages/MainPage/Places/assets/cafe.webp')"
```

Суммарный вес пяти изображений уменьшен с 3 900 708 до 152 908 байт (на 96,1%). `npm run build` выполнена успешно; сборка использует WebP. На `http://localhost:3000/` проверены загрузка всех пяти изображений и внешний вид первого экрана, карточек и кафе после замены.

После `npm run build` команда `npm run test:links` проверяет локальные ссылки собранной главной, адреса SEO, robots/sitemap и преобразование ссылок из старых записей.

- `npm run types` — успешно.
- `npm run build` — успешно; сформирован `build/client/index.html`, CSS лейаута и главной извлечён Linaria.
- В браузере на `http://localhost:3000/` проверены широкая и мобильная компоновки, загрузка пяти изображений, раскрытие меню, закрытие меню с фокусом в поле поиска. На ширине 390 пикселей горизонтальной прокрутки нет. В консоли главной ошибок и предупреждений не обнаружено.
- Отправка поиска ведёт на локальный URL с параметром `name`; незавершённый каталог возвращает 404.

Сборка предупреждает о существующем импорте `os` в Apollo-клиенте. Производственная цепочка Traefik → Varnish → Node.js и HMR через Traefik в рамках этой проверки не проверялись. Публикация не выполнялась. Прежние адреса предварительного рендеринга от другого проекта удалены; пока предварительно рендерится главная.
